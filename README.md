# LCA Self-Healing Playground

Controllable pages to test LCA agentic self-healing. **Same URL the whole time** — the break is driven by a shared flag, so the agentic test never re-records from scratch.

## Toggle the break (no URL change)
- **Button:** repo > Actions > **toggle-heal** > Run workflow > pick `on` / `off` / `gone`.
- **CLI:** `./toggle.sh on` / `./toggle.sh off` / `./toggle.sh gone`.
- Pages reflect the change in ~30-60s. Then re-run the SAME saved agentic test URL: `on` => the captured locator is broken => heal fires; `off` => healthy; `gone` => the checkout action is removed entirely => heals fail until the budget exhausts (unhealable).

Resolution order in `flag.js`: `?v=2`/`?break`/`?gone` (manual, per-tab) > `localStorage.lcaBreak=1` (same browser) > `flag.json` (shared). `?gone=0`/`?break=false` count as off.

## Pages
checkout.html (Checkout drift + decoy; `gone` removes it), frames.html (iframe+shadow), validation.html (`#status-badge` drift; `?remove=1`/`?wrong=1`), visual.html, timing.html (`?delay`), flow.html (mid-step drift), modal.html (random promo popup interrupts mid-flow; close-and-continue, blocked clicks logged; `?popup=1` forces / `?popup=0` suppresses), data.html (`#token`; `?use=`), email.html (verify link/OTP), cookie.html, config.html (run-config inspector: injected headers, cookies, localStorage, basic-auth probe + egress IP/country for the IP-geolocation toggle), download.html (report.txt fixture in `files/`), upload.html (native OS file dialog; expects report.txt back), api.html (renders api/todo.json live + external httpbin failure legs). index.html has the 50-case map; 404.html catches dead URLs.

## Tabs, windows and Custom JS
Four pages for the TC × LCNC agentic surface — multi-tab, multi-window and the Custom-JS console. Shared plumbing lives in `assets/tabkit.js` (cross-context channel, `window.open` wrapper + live registry, Smart-Tab identity parser and score calculator) and `assets/tabtarget.js` (the self-describing identity card every opened target renders).

- **tabs.html** — five openers, five outcomes: a real `target="_blank"` anchor (tab B, *cannot* be closed by script), a scripted open (tab C, can), an identical twin of B (same URL **and** title — only the index separates them), the framed target, a tab that closes itself after 6 s, and one button labelled like an opener that opens nothing. Approving anything in a child tab posts a code to the **handoff inbox** here, so "switch back to tab 1 and validate" asserts a live fact rather than re-reading static copy. Break: `drift` slips a Notifications tab in *front* of the invoice, so it lands on index 2; `gone` drops the invoice entirely. Same URL, same button, same click — only the index moves.
- **windows.html** — SecurePay as a real `window.open` popup (`480×680`, so Chrome makes a window, not a tab). Routes: stays open · auto-closes 3 s after confirmation · two popups at once · redirects itself to `?step=review` after 1.5 s. Inside the popup, *Verify with OTP* opens a **grandchild** window. Merchant-side readouts update live over the channel (`SP-77214`, OTP `902137` — both fixed so they can be asserted exactly). Break: `drift` forces auto-close on every route so the handle vanishes mid-test; `gone` opens nothing.
- **smart-tab.html** — the [Smart Tab Handling](https://browserstack.atlassian.net/wiki/spaces/PROD/pages/5573116195/Smart+Tab+Handling) lab (flag `smart_tab_handling_whitelist`). 18 launchers each move exactly one property: open order, tracking params, path, query, fragment, title, title-mutates-after-load, self-closing, inserted tab, identical twin. The **score oracle** runs the spec's arithmetic live against every open tab and names the expected winner — verified values are `/cart/checkout` **32**, `/store/cart/checkout` **20**, `/account/checkout` **16.67**, and a clean URL ties at 32 with the same URL carrying `utm_*`/`gclid`/`fbclid`. Two interpretations the spec leaves open are stated on the page: segments are matched order-independently, and the denominator is the *recorded* segment count — if the product disagrees, that gap is a finding.
- **console.html** — Custom JS, all three types (**action**, **validation**, **create variable**), each with a copy-paste snippet card and an assertable readout. Every value is deliberately out of reach of a normal step: a canvas-painted balance (no text node, no a11y node — the case where the agent must reach for Custom JS unprompted), `::before` generated content, a shadow-root meter, `sessionStorage`/`localStorage`, a readonly discount field that only reacts to a *dispatched* `input` event, an async hook, a throwing hook, and a volatile ticket that proves a saved step re-executes instead of freezing its value. `?ctx=B` opens a second context whose reference differs (`ORD-99117` vs `ORD-88231`), so the returned value tells you which document the step actually ran in. Break: `drift` relocates every hook to `window.lca.v2.*` and deletes the originals — a recorded snippet then throws, and a Custom-JS step is outside `AIAutoHealer`'s 7 healable action types, so it must fail cleanly rather than quietly recover.

Targets: `tabs/target.html` (query-driven: `?tab` `?title` `?code` `?titledrift` `?autoclose` `?slow`), `tabs/framed.html`, the path family `tabs/cart/checkout.html` · `tabs/account/checkout.html` · `tabs/store/cart/checkout.html`, and `windows/pay.html` · `windows/otp.html`.


## Browser-flag inspector
`flags/index.html` — reads the launched Chrome and reports which of the 8 Advanced-Configuration **browser flags** (auto screen-share, camera/mic, location, clipboard, incognito, block-all, dark mode, language) actually took effect. Point the Automate-with-AI **Explore URL** flow at this URL to verify a run's flags end to end; readouts are live DOM text + a machine-readable snapshot the agent can assert on. `flags/language.html` is the language deep-dive (localized content across all 11 presets, active row highlighted).

Confidence is marked per flag: **strong** (definitive JS signal) vs **heuristic** (incognito quota-gap, dark-mode screenshot swatch — verify by comparing on/off). Incognito on Chrome 133+: quota reports `min(real, usage + 10 GiB)` — a normal profile reads *exactly* usage + 10 GiB while incognito's RAM-derived cap (≈1–4 GiB) shows through, so the gap is the signal; it also catches the #1946 regression where the MCP page swap's `newPage()` dropped an `--incognito` session's agent tab into the normal profile.

The launch path matters: the **live agentic path** (`preCreateSeleniumSession` → `BrowserFlagsHandler`) applies flag **args and prefs**, dedupes repeats, and its defaults already allow clipboard (pref = 1) — so Clipboard *Enabled* is indistinguishable from default, is **not** counted toward the active-toggles metric (a zero-flag control run reads 0 / 7), and only *Disabled* is observable. Since lcnc-services **#1946** + lcnc-backend **#4486**, the **validation replay** and **Argus cached-run** paths route through the same canonical handler + agent overlay (args **and** prefs), the locale finally applies on the live agent session (`intl.accept_languages`), and group-level popup-suppression defaults are overridable fallbacks — the user's catalog choice wins. **All run types should now read identically on these pages; a per-run-type mismatch is the regression signal.** (Pre-fix: the replay paths dropped user flags entirely and force-denied geolocation/camera/mic; the older **pwCaps path** appended a 7-flag hand-picked subset, args only.)

`flags/diff.html` — **launch diff**: renders the default LCNC Chrome command line (desktop-app or cloud-agentic baseline), verifies the baseline's JS-observable fingerprints (`navigator.webdriver`, `window.gc`, File-System-Access APIs stripped, autoplay policy…), and overlays the extra args/prefs inferred live from the 8 user flags — so you can *see* what a run added on top of the defaults. Probes auto-run when permission states are pre-decided (agentic runs), so it self-populates with zero clicks; `?noauto=1` disables.
