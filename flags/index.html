Flag probes

8 flags · order matches the modal

Reading the results — the launch path matters. The live agentic path (preCreateSeleniumSession → BrowserFlagsHandler) applies flag args and prefs, dedupes repeats, and its defaults already allow clipboard (pref = 1). Since lcnc-services #1946 + lcnc-backend #4486, the validation replay and Argus cached-run paths route through the same canonical handler and agent overlay — args and prefs — and group-level popup-suppression defaults became overridable fallbacks (the user's own catalog choice wins). All run types should now read identically here; a per-run-type mismatch on this page is the regression signal. On pre-fix builds the replay paths dropped user flags entirely and the older pwCaps path appended args only. Confidence per card: strong (definitive JS signal) vs heuristic (inferred — verify by comparing on/off). See the launch diff for the full command-line picture.

Incognito mode

incognito
checking…

Launches the browser in an Incognito window.

Incognito mode — checking…

Chrome args when enabled

  • --incognito
signal · heuristic (quota gap)

No isIncognito API. Chrome 133+ reports quota as min(real, usage + 10 GiB): a normal profile reads exactly usage + 10 GiB, while incognito's smaller RAM-derived cap (≈1–4 GiB) shows through — the gap is the signal. This catches the lcnc-services #1946 regression where the agent's tab silently escaped incognito (newPage() → normal profile → full 10 GiB gap). High-RAM hosts can mask it — confirm via the run's UI/video when it matters.
